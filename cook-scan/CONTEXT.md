# CONTEXT

このプロジェクトのドメイン用語集（グロッサリー）。実装の詳細は書かず、言葉の意味と境界だけを定義する。

## 用語

### 参照レシピ (Reference Recipe)

AIレシピチャットの対話の中で、ユーザーが既存の自分のレシピを文脈として持ち込んだもの。
AIはこの参照レシピを「素材」として扱い、合成・アレンジして新しい**レシピ下書き**を生成する。

- 複数の参照レシピを同時に持ち込める（例：2つのレシピを合体させる）。
- 参照レシピそのものは変更されない。あくまで新しい下書きを生む入力。
- 一度持ち込むと、その会話セッションの間は保持される（明示的に外すまで文脈に残る）。
- ユーザー本人のレシピだけが対象。サーバーが所有権を検証して取得する。

関連: [[レシピ下書き]]

### レシピ下書き (Recipe Draft)

AIレシピチャットがユーザーとの対話の結果として生成する、保存前のレシピ案。
タイトル・材料・手順・メモを持つ。ユーザーが確認・編集してから保存すると正式な**レシピ**になる。

- まだ永続化されていない（DBの recipes テーブルには存在しない）状態を指す。
- 保存して初めて recipes / ingredients / steps として永続化される。

関連: [[参照レシピ]]
